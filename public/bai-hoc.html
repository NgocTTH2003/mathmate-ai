Phương trình lượng giác cơ bản

Sau bài này, bạn giải được các phương trình dạng \(\sin x = m\), \(\cos x = m\), \(\tan x = m\), \(\cot x = m\) và viết đúng các họ nghiệm.

MathMate giảng, khoảng 3 phút. Đây là bản thử nghiệm chưa có giọng đọc.

Phương trình \(\sin x = m\)

Vì \(-1 \le \sin x \le 1\), số nghiệm của phương trình phụ thuộc vào \(m\).

  • Nếu \(|m| > 1\): phương trình vô nghiệm.
  • Nếu \(|m| \le 1\): gọi \(\alpha\) là góc sao cho \(\sin\alpha = m\). Khi đó $$\sin x = \sin\alpha \iff \left[\begin{aligned} x &= \alpha + k2\pi \\ x &= \pi - \alpha + k2\pi \end{aligned}\right. \quad (k\in\mathbb{Z})$$

Phương trình \(\sin x = \sin\alpha\) luôn có hai họ nghiệm. Đây là lỗi hay gặp nhất: chỉ viết họ thứ nhất rồi dừng.

Các trường hợp đặc biệt nên nhớ:

$$\begin{aligned} \sin x = 0 &\iff x = k\pi \\ \sin x = 1 &\iff x = \frac{\pi}{2} + k2\pi \\ \sin x = -1 &\iff x = -\frac{\pi}{2} + k2\pi \end{aligned}$$

Phương trình \(\cos x = m\)

Tương tự, phương trình vô nghiệm khi \(|m| > 1\). Khi \(|m| \le 1\), gọi \(\alpha\) là góc sao cho \(\cos\alpha = m\):

$$\cos x = \cos\alpha \iff x = \pm\alpha + k2\pi \quad (k\in\mathbb{Z})$$
$$\begin{aligned} \cos x = 0 &\iff x = \frac{\pi}{2} + k\pi \\ \cos x = 1 &\iff x = k2\pi \\ \cos x = -1 &\iff x = \pi + k2\pi \end{aligned}$$

Phương trình \(\tan x = m\) và \(\cot x = m\)

Hai phương trình này có nghiệm với mọi \(m\). Chú ý điều kiện xác định: \(\tan x\) cần \(x \ne \frac{\pi}{2} + k\pi\), còn \(\cot x\) cần \(x \ne k\pi\).

$$\begin{aligned} \tan x = \tan\alpha &\iff x = \alpha + k\pi \\ \cot x = \cot\alpha &\iff x = \alpha + k\pi \end{aligned} \qquad (k\in\mathbb{Z})$$

Với \(\tan\) và \(\cot\), chu kỳ là \(\pi\) nên họ nghiệm dùng \(k\pi\), không phải \(k2\pi\).

Ví dụ

Ví dụ 1.Giải phương trình \(\sin x = \dfrac{1}{2}\).
Ta có \(\dfrac{1}{2} = \sin\dfrac{\pi}{6}\), nên $$\sin x = \sin\frac{\pi}{6} \iff \left[\begin{aligned} x &= \frac{\pi}{6} + k2\pi \\ x &= \pi - \frac{\pi}{6} + k2\pi = \frac{5\pi}{6} + k2\pi \end{aligned}\right. \quad (k\in\mathbb{Z})$$
Ví dụ 2.Giải phương trình \(\cos 2x = -\dfrac{\sqrt{2}}{2}\).
Ta có \(-\dfrac{\sqrt{2}}{2} = \cos\dfrac{3\pi}{4}\), nên $$\cos 2x = \cos\frac{3\pi}{4} \iff 2x = \pm\frac{3\pi}{4} + k2\pi \iff x = \pm\frac{3\pi}{8} + k\pi \quad (k\in\mathbb{Z})$$ Chú ý: chia cả \(k2\pi\) cho 2 thành \(k\pi\).
Ví dụ 3.Giải phương trình \(\tan\left(x - \dfrac{\pi}{4}\right) = \sqrt{3}\).
Ta có \(\sqrt{3} = \tan\dfrac{\pi}{3}\), nên $$x - \frac{\pi}{4} = \frac{\pi}{3} + k\pi \iff x = \frac{7\pi}{12} + k\pi \quad (k\in\mathbb{Z})$$ Nghiệm này thỏa điều kiện \(x - \frac{\pi}{4} \ne \frac{\pi}{2} + k\pi\).
