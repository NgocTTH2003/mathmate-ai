Giải phương trình \(2\sin x - \sqrt{3} = 0\)
  1. \(\sin x = \dfrac{\sqrt{3}}{2}\)
    Chuyển vế và chia hai vế cho 2, chính xác.
  2. \(\sin x = \sin\dfrac{\pi}{3}\)
    Nhận ra góc đặc biệt, rất tốt.
  3. \(x = \dfrac{\pi}{3} + k2\pi,\ k\in\mathbb{Z}\)
    Họ nghiệm thứ nhất đúng.
  4. \(x = \pi - \dfrac{\pi}{3} + k2\pi = \dfrac{2\pi}{3} + k2\pi\)
    Bạn còn thiếu họ nghiệm này. Nhớ: \(\sin x = \sin\alpha\) luôn cho hai họ nghiệm.
